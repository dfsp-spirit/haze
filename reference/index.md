# Package index

## All functions

- [`fwhm2niters()`](https://dfsp-spirit.github.io/haze/reference/fwhm2niters.md)
  : Convert FreeSurfer Gaussian smoothing FWHM to number of NN smoothing
  iterations.
- [`haze`](https://dfsp-spirit.github.io/haze/reference/haze-package.md)
  [`haze-package`](https://dfsp-spirit.github.io/haze/reference/haze-package.md)
  : haze: Smoothing of per-vertex data on triangular meshes
- [`linear_interpolate_kdtree()`](https://dfsp-spirit.github.io/haze/reference/linear_interpolate_kdtree.md)
  : Interpolate per-vertex data at the query points. Or map per-vertex
  data between subjects.
- [`mesh.adj()`](https://dfsp-spirit.github.io/haze/reference/mesh.adj.md)
  : Compute vertex neighborhoods for a mesh.
- [`mesh.neigh.pre()`](https://dfsp-spirit.github.io/haze/reference/mesh.neigh.pre.md)
  : Return pre-computed neighborhood data for specific meshes.
- [`niters2fwhm()`](https://dfsp-spirit.github.io/haze/reference/niters2fwhm.md)
  : Convert number of NN smoothing iterations to a FreeSurfer Gaussian
  smoothing FWHM.
- [`nn_interpolate_kdtree()`](https://dfsp-spirit.github.io/haze/reference/nn_interpolate_kdtree.md)
  : Get per-vertex data at vertices closest to the given query
  coordinates on the mesh.
- [`pervertexdata.smoothnn()`](https://dfsp-spirit.github.io/haze/reference/pervertexdata.smoothnn.md)
  : Smooth per-vertex data based on mesh.
- [`pervertexdata.smoothnn.adj()`](https://dfsp-spirit.github.io/haze/reference/pervertexdata.smoothnn.adj.md)
  : Smooth per-vertex data using nearest-neighbor smoothing based on
  mesh adjacency information.
- [`read.vv()`](https://dfsp-spirit.github.io/haze/reference/read.vv.md)
  : Read vv binary file.
- [`submesh.vertex()`](https://dfsp-spirit.github.io/haze/reference/submesh.vertex.md)
  : Create a submesh including only the given vertices.
